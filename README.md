# 百战异闻录 · 技能管理

一款用于管理《剑网 3》百战异闻录角色技能的离线 Flutter 应用，适合同时记录多个角色的技能重数、精神值、耐力值及通本需求。

## 主要功能

- 多角色管理：支持新增、编辑、删除、排序及快速切换角色，并根据角色性别匹配对应技能。
- 快速录入：新增角色时可统一设置全部技能重数，也可在 macOS 和 Windows 上通过 Excel 或技能截图识别导入。
- 导入预览：导入后可预览角色信息、精神与耐力统计，以及按 Boss 分组的技能重数；确认前可展开并手动调整。
- 技能统计：按角色、Boss、技能和重数筛选全部技能，Boss 与技能采用可展开的二级结构展示。
- 重点追踪：集中查看重要技能和紫色技能，并支持搜索、筛选和直接调整重数。
- 通本需求：依据当前角色的技能重数统计各重数档位的通本需求。
- Boss 技能管理：维护 Boss 类型、显示顺序、精神与耐力提升及所属技能；基础技能信息修改后会同步到已有角色。
- 在线数据更新：启动时自动检查仓库中的 Boss 技能数据版本，发现更新后由用户确认同步，并保留角色现有技能重数。
- 数据迁移：支持 Boss 与技能的导入导出，以及应用数据的本地备份和恢复。
- 多设备同步：支持 WebDAV 版本化备份、自动同步和较新云端备份检测；检测到其他设备的新数据时会先提示恢复，避免直接覆盖。
- 本地使用：数据保存在本机，无需联网即可使用。

## 技能与属性规则

- 技能重数范围为 1–10 重。
- 精神值和耐力值会根据技能重数及 Boss 属性提升自动计算。
- 同一 Boss 的精神提升与耐力提升合计必须为 800。
- 部分 Boss 技能会根据角色性别显示不同名称和属性结果。

## 运行项目

```bash
flutter pub get
flutter run -d macos
```

也可以选择 Flutter 支持的其他桌面端或移动端设备运行。

## 测试

```bash
flutter test --no-pub
flutter analyze
```

## 发布 Boss 技能数据

公共 Boss 技能数据位于 `data/baizhan-bosses.json`。修改内容后必须同时递增文件中的 `version`，并填写 `updatedAt` 和 `notes`；推送到 `main` 分支后，其他使用者启动软件时会收到更新提示。
