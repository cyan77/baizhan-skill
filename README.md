# 百战异闻录 · 技能统计

一个离线运行的 Flutter 多角色技能统计工具，初始数据来自 `season4 v4.1.xlsx`。

## 功能

- 初始提供一男一女两个示例角色，可增删改和改名，维护性别、门派、心法与 `t / 奶 / dps` 定位。
- 精神值和耐力值按技能重数、Boss 精耐提升及阈值奖励自动计算，角色编辑时无需录入基准值。
- 桌面端使用左侧导航，手机端使用底部导航；角色页支持左右滑动切换角色，展示每个角色的完整精耐、技能和通本数据。
- 首页显示当前角色概览；角色管理支持角色增删改名及维护性别、门派、心法与 `t / 奶 / dps` 定位。
- 重要技能和紫色技能汇总支持按技能、角色、心法、定位筛选，并以角色矩阵显示同步重数。
- 所有技能汇总支持横向切换角色，并按 Boss 名称和最高重数筛选，例如筛选 9 重会显示 9 重及以下的 Boss 技能。
- Boss 技能管理支持新增、编辑、删除 Boss，以及逐条新增、重命名、删除和设置可交易技能。
- 设置页提供外观说明、本地自动保存，以及 JSON 备份导入导出。
- 点击技能可以修改 0–10 重，并通过文件选择器附加技能图片。
- 数据自动保存在本机，无需联网。

## 运行

```bash
flutter pub get
flutter run -d macos
```

也可以使用 Android、Windows 或 Linux 对应设备运行。

## 校验

```bash
flutter test --no-pub
flutter build macos --debug --no-pub
```
